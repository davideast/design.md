§ 1.The Loop

The ReAct (Reason + Act) loop is the fundamental primitive of modern agentic systems. Unlike a simple pipeline where a prompt leads directly to a final answer, ReAct introduces a recursive structure. The model is prompted to generate a "thought"—an internal reasoning trace—before selecting an "action" to execute in the environment. The result of that action, the "observation", is then appended back into the model's context. This feedback loop allows the agent to gather missing information and refine its strategy dynamically. It effectively transforms the LLM from a static predictor into a closed-loop controller.

Fig. 1. The basic loop. Note that OBSERVE returns to THINK; this is what makes the architecture a controller, not a pipeline.

§ 3.Four Architectures

REACT

The standard reasoning-action cycle.

REFLEXION

Adds a MEMORY node to the basic cycle for self-correction.

PLAN-AND-EXECUTE

Adds a PLAN node feeding the execution cycle.

TREE-OF-THOUGHTS

Branches THINK into child nodes before acting.

§ 4.Where Loops Fail

Context-window exhaustion is the silent killer of agentic loops. As the THINK-ACT-OBSERVE cycle repeats, the prompt grows monotonically. With each iteration, the model must attend over an increasingly dense history. Eventually, the signal-to-noise ratio collapses, leading to circular reasoning.

§ 5.The Loop, in Code

def agent_loop(task): history = [SystemPrompt(task)] while True: # THINK thought = llm.generate(history, stop="ACT") # ACT action, params = parse(thought) if action == "FINAL_ANSWER": return params # OBSERVE result = tools.call(action, params) history.append(f"T: {thought} O: {result}") if len(history) > MAX_TURNS: break
The model externalizes its reasoning before committing to an action.
Actions are structured tool calls parsed from the completion.
The observation is injected back into the prompt for the next turn.

The structure strictly interleaves reasoning and action. Forcing the model to externalize its thought before acting gives the system interpretability and reduces hallucinated state changes.

"The architecture is the loop. Everything else is a refinement of how the loop decides what to do next."
