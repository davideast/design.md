§ 1. The Loop

The ReAct (Reason + Act) loop is the fundamental pattern of autonomous agents. It breaks the generation process into discrete steps where the model interleaves textual reasoning with external actions. Instead of generating a single completion, the model predicts a thought process, selects a tool, and pauses execution. The system then executes that tool and feeds the result back into the model's context. This closes the feedback loop, allowing the model to adapt its strategy based on real-world feedback rather than relying solely on internal weights, transforming the static LLM into a dynamic controller.

§ 2. A Worked Trace

Query: "What was the closing price of NVDA the day after Jensen Huang's 2024 keynote?"
THOUGHT: I need to find the date of Jensen Huang's 2024 GTC keynote.
Step 1: Identifying the missing temporal anchor.
ACTION: search("Jensen Huang 2024 keynote date")
OBSERVE: "Jensen Huang delivered the GTC keynote on March 18, 2024."
THOUGHT: The keynote was March 18. The day after is March 19, 2024.
Step 2: Logical deduction from observation.
ACTION: finance_lookup("NVDA", "2024-03-19")
OBSERVE: "NVDA closed at $893.98 on March 19, 2024."
THOUGHT: I have the closing price. I can now answer the user.
Step 3: Terminal condition met.
ANSWER: The closing price of NVDA on March 19, 2024, was $893.98.

§ 3. Four Architectures

REACT

Direct cycle between reasoning and tool execution.

REFLEXION

Reflexion adds a MEMORY node to store critiques and past failures.

PLAN-AND-EXECUTE

Plan-and-Execute adds a PLAN node that decomposes tasks before the cycle.

TREE-OF-THOUGHTS

Tree-of-Thoughts branches THINK into multiple potential paths before acting.

§ 4. Where Loops Fail

Agent loops are inherently resource-intensive. Every iteration appends the previous thought, action, and observation to the prompt, leading to linear growth in context size but a non-linear degradation in reasoning quality. As the history grows, "lost in the middle" phenomena and attention degradation occur. Context-window exhaustion isn't just about hitting a hard limit; it's about the erosion of the model's ability to reason over its own history, leading to repetitive loops or hallucinated tool outputs.

Most production agents fail somewhere in this region — not because the model is incapable, but because the context has become longer than the model's effective attention.

§ 5. The Loop, in Code

def run_agent(prompt): context = [SystemMessage(prompt)] while True: # THINK thought = model.gen(context, stop=["ACT:"]) context.append(thought) # ACT action = extract_action(thought) if not action: break # OBSERVE result = tools.execute(action) context.append(f"OBSERVE: {result}") return context.last() # The structure strictly interleaves reasoning and action. # Forcing the model to externalize its thought before acting # gives the system interpretability and reduces hallucinated # state changes.
THINK: The model generates internal monologue, predicting the next necessary step.
ACT: Execution is paused; the host environment intercepts the tool call.
OBSERVE: External reality is injected back into the immutable prompt history.
