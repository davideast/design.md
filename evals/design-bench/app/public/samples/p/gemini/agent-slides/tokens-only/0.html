§ 1. The Loop

The ReAct loop (Reasoning and Acting) fundamentalizes the agentic workflow by combining internal thought processes with external tool interactions. Instead of a linear sequence where a model predicts a final answer, the loop structures the model's output into distinct phases. First, the model generates a thought process to deliberate on the problem. Second, it selects an action—calling a tool or an API. Third, it receives an observation from the environment. Crucially, this observation feeds back into the next iteration of thought, allowing the model to correct errors and maintain a stateful progression toward a goal.

§ 4. Where Loops Fail

Context-window exhaustion remains the primary failure mode for long-running agentic loops. As the trace grows, the input sequence for each subsequent THINK step expands. This growth is often non-linear, as models may re-summarize or include rich tool outputs. Eventually, the density of information exceeds the model's effective context window. The attention mechanism begins to blur distal thoughts, leading to repetitive actions or a complete loss of the original objective despite the model technically remaining within its token limit.

§ 5. The Loop, in Code

// 1. Internal reasoning step
// 2. Action selection
// 3. Environmental feedback
def run_agent(query):
    history = [f"User: {query}"]
    while True:
        # THINK
        thought = llm.generate(history + ["Thought:"])
        history.append(f"Thought: {thought}")

        # ACT
        action = llm.generate(history + ["Action:"])
        history.append(f"Action: {action}")

        if "Final Answer" in action:
            return action

        # OBSERVE
        obs = execute_tool(action)
        history.append(f"Observation: {obs}")

The structure strictly interleaves reasoning and action. Forcing the model to externalize its thought before acting gives the system interpretability and reduces hallucinated state changes.

§ 6. Ending

The architecture is the loop. Everything else is a refinement of how the loop decides what to do next.
