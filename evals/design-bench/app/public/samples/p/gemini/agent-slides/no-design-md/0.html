§ 1. The Loop

The core of modern agentic systems is the transition from a linear pipeline to a closed-loop controller. In a standard inference pass, the model maps input to output. In a ReAct (Reason + Act) loop, the model generates a thought (internal state), an action (external tool call), and receives an observation (environmental feedback). This feedback is appended back into the context window. By iterating this sequence, the agent can resolve complex, multi-step queries that require external data or state changes. The loop allows the model to correct its own path based on real-world results rather than relying on a static internal representation.

§ 2. A Worked Trace

Query: "What was the closing price of NVDA the day after Jensen Huang's 2024 keynote?"
THOUGHT Need to identify the specific date of the GTC 2024 keynote.
Initial step: Decomposing a temporal query.
ACTION Search("Jensen Huang GTC 2024 keynote date")
OBSERVE "The GTC 2024 keynote took place on March 18, 2024."
External data injected into context.
THOUGHT The day after the keynote is March 19, 2024. Now looking for NVDA closing price.
ACTION StockLookup("NVDA", "2024-03-19")
Tool selection based on refined state.
OBSERVE "Date: 2024-03-19, Close: $893.98"
THOUGHT The closing price on March 19, 2024, was $893.98. No stock splits occurred between then and now.
ACTION Finish("The closing price was $893.98.")
Terminal action triggered by goal satisfaction.

§ 3. Four Architectures

REACT
Standard interleaving of thought, action, and observation.
REFLEXION
Adds a MEMORY/EVAL node to refine the loop based on past failures.
PLAN-AND-EXECUTE
Adds a PLAN node that pre-calculates steps before entering the loop.
TREE-OF-THOUGHTS
Branches THINK into multiple candidates to find the optimal path.

§ 4. Where Loops Fail

The primary constraint on autonomous loops is the finite context window. As the number of iterations increases, the history of thoughts, actions, and observations grows linearly or super-linearly if observations are large. Eventually, the model enters a "lost-in-the-middle" regime or exceeds its total token budget. Performance degrades sharply at this inflection point as the model loses access to initial goals or fails to attend to critical previous observations.

Roughly 80% of agentic errors in production derive from context-drift or window saturation rather than logic failure.

§ 5. The Loop, in Code

def run_agent(task, tools, model): history = [f"Task: {task}"] while True: # THINK thought = model.generate(history, stop=["ACT:"]) history.append(f"THOUGHT: {thought}")
1. The model reviews history and latent state to decide the next action.
# ACT action_call = model.generate(history, start="ACT:") if "FINISH" in action_call: return action_call
2. Action is parsed and executed against external APIs/Env.
# OBSERVE result = tools.execute(action_call) history.append(f"OBSERVE: {result}")
3. Environment feedback is strictly appended to ensure causal history.
if len(history) > MAX_CONTEXT: history = summarize(history)

The structure strictly interleaves reasoning and action. Forcing the model to externalize its thought before acting gives the system interpretability and reduces hallucinated state changes.
