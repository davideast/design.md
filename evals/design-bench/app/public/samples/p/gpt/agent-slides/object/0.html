§ 1. the loop

§ 1. The Loop

The ReAct loop is the simplest useful shape for an agent. At each turn the model first thinks: it makes a local interpretation of the task, the evidence so far, and the next useful move. It then acts by calling a tool, issuing a search, running code, or asking for data. The world answers with an observation. That observation is appended to the trace, changing what the model knows, and the next thought is conditioned on the updated record. ReAct is therefore not a chain of prompts but a feedback controller written in language.

§ 4. where loops fail

§ 4. Where Loops Fail

Agent loops consume context as they operate. Each thought, tool call, result, retry, and correction is appended to the trace so that future decisions can see the past. This is useful until it is not. After enough iterations, the model is no longer reasoning over a compact state; it is searching through a transcript. Failures then look like stubbornness, forgotten constraints, duplicated actions, or confident answers based on the wrong part of the history.

§ 5. the loop, in code

§ 5. The Loop, in Code

def react(model, tools, question, max_steps=8):
    trace = []
    state = {"question": question}

    for i in range(max_steps):
        prompt = render_prompt(question, trace)

        thought = model.generate(
            prompt,
            stop=["ACTION:"]
        )
        trace.append(("THOUGHT", thought))

        action = model.generate_action(
            prompt + thought,
            tools=tools
        )
        trace.append(("ACTION", action))

        if action.name == "finish":
            return action.arguments["answer"], trace

        observation = tools[action.name](
            **action.arguments
        )
        trace.append(("OBSERVATION", observation))

        state = update_state(state, observation)

    return summarize_failure(trace), trace

THINK: ask the model for a local interpretation before any side effect.

ACT: restrict the next move to an explicit tool call or finish action.

OBSERVE: append the world's reply to the trace, then loop.

The structure strictly interleaves reasoning and action. Forcing the model to externalize its thought before acting gives the system interpretability and reduces hallucinated state changes.
