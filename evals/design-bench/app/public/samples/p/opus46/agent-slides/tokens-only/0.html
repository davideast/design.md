§ 1. The Loop

At its core, an agent is a loop. The ReAct framework introduced the idea that a language model should interleave reasoning with action: first think about what to do, then act on the world, then observe the result. The cycle repeats until the task is complete or a termination condition is met. This THINK → ACT → OBSERVE loop is the minimal viable architecture for tool-using agents. Everything else — memory, planning, reflection — is scaffolding built around it.

§ 2. A Worked Trace

USER → "What was NVDA's closing price yesterday and how does it compare to its 52-week high?"
Thought I need to look up NVDA's most recent closing price. I'll query a financial data API. ← reasoning before acting
Action search_api(query="NVDA closing price today") ← tool invocation
Observe {"symbol": "NVDA", "close": 142.56, "date": "2026-10-13"} ← structured return value
Thought Now I need the 52-week high to compute the comparison.
Action search_api(query="NVDA 52-week high")
Observe {"symbol": "NVDA", "52_week_high": 168.91, "date": "2026-07-22"} ← second retrieval cycle
Thought 142.56 / 168.91 ≈ 0.844 → NVDA is trading ~15.6% below its 52-week high. ← arithmetic in context
Action respond("NVDA closed at $142.56 on Oct 13, ~15.6% below its 52-wk high of $168.91.") ← final answer, loop exits

§ 4. Where Loops Fail

Every iteration costs tokens. Worse, accuracy often degrades after a threshold number of iterations as the context window fills with redundant observations. The agent begins to repeat actions, hallucinate tool outputs, or lose track of its original goal. Bounded loops with early-exit heuristics help, but the fundamental tension remains: more iterations increase coverage at the cost of coherence.

§ 5. The Loop, in Code

from dataclasses import dataclass from typing import Callable @dataclass class Trace: steps: list[dict] done: bool = False def react_loop( model: Callable, tools: dict[str, Callable], query: str, max_iter: int = 10, ) -> Trace: trace = Trace(steps=[]) for i in range(max_iter): thought = model.think(query, trace) # ① action = model.act(thought) # ② result = tools[action.name](*action.args) trace.steps.append({ "thought": thought, "action": action, "observation": result, }) if action.name == "finish": # ③ trace.done = True break return trace

Twenty-eight lines. The rest is prompt engineering.

① Think

The model generates a chain-of-thought conditioned on the full trace so far.

② Act

A structured action is extracted — function name and arguments — then dispatched.

③ Exit

The loop terminates on a sentinel action. Without it, you burn tokens until max_iter.
