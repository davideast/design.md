§ 1

The Loop

Every capable agent reduces to a single iterative pattern: perceive, reason, act, and observe consequences. The model generates a thought — an internal monologue framing the problem — selects an action from a vocabulary of tools, executes it against the world, and incorporates the resulting observation into its context window. This loop continues until a terminal condition is met: an answer is produced, a budget is exhausted, or the model determines no further steps are needed.

A Worked Trace

Query: "What was NVDA's closing price on 2024-01-15?"
THOUGHT 1I need NVDA's closing price for a specific date. I'll query the financial data API.
ACTION 1get_stock_price(ticker="NVDA", date="2024-01-15")
OBSERVATION 1Error: Market closed on 2024-01-15 (Martin Luther King Jr. Day).
THOUGHT 2The market was closed. I need to find the last open trading day before Jan 15.
ACTION 2get_trading_calendar(from="2024-01-12", to="2024-01-15")
OBSERVATION 2Trading days: [2024-01-12]. Last open: Friday, January 12.
ACTION 3get_stock_price(ticker="NVDA", date="2024-01-12")
OBSERVATION 3NVDA closed at $547.10 on 2024-01-12. Note: requested date was a holiday.
Thought articulates plan before any tool call.
Error is informative; recovery is graceful.
Calendar query supplies needed context for repair.
Answer grounds with explicit date caveat.

§ 3

Four Architectures

REACT

The minimal closed loop. Thought, action, observation — each completing the circuit before the next begins.

REFLEXION

The loop with a self-loop: after failure, the agent circles back through verbal self-critique before rejoining the outer loop.

PLAN-AND-EXECUTE

The outer loop contains inner loops. A plan decomposes into steps; each step is a small closed loop of action and observation.

TREE-OF-THOUGHTS

The loop opens into branches, then closes on the best path. The returning arc (vermilion) selects which branch completes the cycle.

04
§ 4

Where Loops Fail

The loop's cost is cumulative. Every iteration extends the context window; every token consumed narrows future options. The agent performs well until an inflection point — beyond it, the loop runs but the model cannot. Context overflow silently corrupts earlier reasoning. The loop continues; the coherence does not.

The Loop, in Code

def react_loop(query: str, tools: dict, max_steps: int = 10) -> str:
    history = [
        {"role": "system", "content": SYSTEM_PROMPT},
        {"role": "user",   "content": query},
    ]

    for step in range(max_steps):          # budget guard
        response = llm.complete(history)
        thought, action = parse(response)

        if action.is_final():              # terminal check
            return action.value

        tool_fn = tools[action.name]
        observation = tool_fn(**action.args)

        history.extend([                    # grow context
            {"role": "assistant", "content": response},
            {"role": "user",
             "content": f"Observation: {observation}"},
        ])

    raise RuntimeError("Max steps exceeded")

The loop is twenty lines. The difficulty is in everything that surrounds it.

L 7

max_steps is a hard budget — the only guaranteed termination.

L 11

The model decides when it is done. is_final() checks for a terminal token.

L 17

History grows monotonically. No forgetting — until the window fills.
