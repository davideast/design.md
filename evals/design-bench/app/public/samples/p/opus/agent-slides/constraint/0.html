§ 1

The Loop

Every agent, regardless of its scaffolding, reduces to a single primitive: a loop. The model thinks about the current state, selects an action from its available tools, executes that action in the environment, and observes the result. The observation feeds back into the next cycle of thought. The loop terminates when the model emits a final answer or an iteration budget is exhausted. Everything else — memory, planning, reflection — is decoration atop this core.

A Worked Trace

USER QUERY
"What was NVDA's closing price
yesterday, and is it above
the 50-day moving average?"
01 Think: I need NVDA's closing price. I'll call the market data tool.
02 Act: get_price(symbol="NVDA", date="2026-10-13")
03 Observe: Returns {"close": 142.58, "currency": "USD"}
04 Think: Now I need the 50-day moving average for comparison.
05 Act: get_moving_avg(symbol="NVDA", window=50)
06 Observe: Returns {"sma_50": 138.21}
07 Think: 142.58 > 138.21 — the price is above the SMA. I can answer.
08 Answer: NVDA closed at $142.58, which is above its 50-day moving average of $138.21.

Where Loops Fail

An unchecked loop is a liability. Each iteration consumes tokens, and cost scales linearly while task completion often plateaus. After roughly eight iterations the model begins to repeat itself or hallucinate tool outputs. Guardrails — iteration caps, token budgets, and self-evaluation checkpoints — are not optional; they are structural requirements of any deployed agent.

The Loop, in Code

def agent_loop(
    model,
    tools: dict,
    query: str,
    max_iter: int = 10
) -> str:
    messages = [{"role": "user",
                 "content": query}]

    for i in range(max_iter):
        # THINK
        response = model.generate(messages)

        if response.is_final_answer:
            return response.text

        # ACT
        tool = tools[response.tool_name]
        result = tool(**response.tool_args)

        # OBSERVE
        messages.append({
            "role": "tool",
            "name": response.tool_name,
            "content": str(result)
        })

    raise TimeoutError("budget exhausted")

Twenty-five lines capture the entire primitive. The model generates until it decides to stop or the budget runs out. Everything in the scaffolding literature — ReAct, Reflexion, LATS — is a variation on this loop with additional memory structures or branching strategies inserted at the three marked phases.
