# Brief — treatment sheet

Design a desktop web page that shows every rendering produced by one treatment of one case, side by side at equal size. The reader's question is consistency: given the same input twenty-two times, how much did the results agree? This brief carries content only — all visual direction comes from the project's DESIGN.md.

The page contains, in sequence:

## 1. Wayfinding

A link back to "Agent Architecture — all treatments," and the sheet's identity, which is one treatment on one tool: "One real object · Stitch · Gemini 3.1 Pro — all 22 renderings."

## 2. The reading line

Two sentences framing what the reader is looking at: "Every image below came from the same input: the shared tokens plus one named artifact, a graduate CS lecture handout. How much the results agree is itself a finding — direction that grounds also stabilizes."

## 3. The sheet

All 22 renderings at equal size in a consistent arrangement (use placeholder images), each with a minimal caption: its number ("1 of 22" through "22 of 22") and its individual distance from the default look (values ranging between 0.88 and 1.02 — use 0.95 ± a small spread). Each rendering opens its detail page.

## 4. The consistency claim

One sentence beneath the sheet: "The 22 renderings sit within 0.14 of each other — the tightest spread of any treatment in this case. The adjective treatment's spread across the same count is 0.41: same words, much wider wandering."

## 5. Certification

A closing block in the register the page reserves for machine-quoted values: tool Stitch · Gemini 3.1 Pro · 22 renderings · case definitions hash 5d7280c55ee4 · measured 2026-06-10. Distances here are from this tool's own default look.
