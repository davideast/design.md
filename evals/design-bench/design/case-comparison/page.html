Agent Architecture — a slide deck for a technical talk.

This case investigates the effectiveness of different instructional methods for style direction when generating technical slide decks.

The Claim Adjectives are inefficient. Describing a design with a single concrete object or governing metaphor produces outcomes significantly further from the default look than lists of stylistic adjectives.

No direction

The model received the brief alone. This is the default look everything below is measured against.

Distance 0.00

Tokens only

The shared palette and type choices, with no words about how to use them.

Distance 0.18

Adjectives

The shared tokens, plus a description in adjectives: scholarly, restrained, print-like. Adjectives are the method being challenged.

Distance 0.31
+0.64

One real object

The shared tokens, plus one artifact named precisely: a graduate CS lecture handout.

Distance 0.95

One hard constraint

Plus one limitation: everything must survive photocopying.

Distance 0.71

One governing metaphor

Plus one idea mapped onto every element: each slide is a page from a professor's working notebook.

Distance 0.66

Full specification

The complete designer-grade specification. The ceiling the shorter methods reach toward.

Distance 1.02

The Insight Naming a specific, recognizable artifact ("graduate CS lecture handout") forces the model to synthesize a cohesive visual system rather than blindly applying disconnected adjectives.
