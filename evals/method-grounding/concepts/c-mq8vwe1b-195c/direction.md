# The Hi-Fi Deck

This world is an industrial, rack-mounted Tascam or Sony tape deck from the early 1990s. It rejects the fluidity of modern "glass" interfaces in favor of the rigid, heavy physics of professional audio hardware.

The interface is a single sheet of brushed obsidian metal. Every interactive element is a physical affordance: chunky, beveled plastic keys for transport controls and recessed glass windows for the Vacuum Fluorescent Display (VFD). Typography is divided into two roles: "Silk-screened" labels (white or light gray mono-spaced text) that describe the functions of the machine, and "Glow" text (Cyan VFD) that represents the live data.

The layout is dense and calibrated. It uses hard edges and subtle inner shadows to create the feeling of parts being machined into a faceplate. There are no soft shadows or organic shapes. The logic of the interface is the logic of a machine: if a button is "pressed," it is physically recessed; if a mode is active, an orange LED indicator is lit. It is a high-precision tool, built for durability and technical performance over "user friendliness."
