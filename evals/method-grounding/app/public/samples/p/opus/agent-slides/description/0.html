§ 1

The Loop

The ReAct loop is the smallest complete unit of agency. The model is not asked to answer in one pass; instead it cycles. It thinks — producing a short natural-language reasoning trace about what to do. It then acts — emitting a structured call to a tool or the environment. It observes the result returned to it. Crucially, that observation is fed back as new context, and the model thinks again. Each turn refines the model's picture of the world. The loop continues until the model judges the task complete and emits a final answer rather than another action.

§ 2

A Worked Trace

Query: "What was the closing price of NVDA the day after Jensen Huang's 2024 keynote?"
THOUGHT I need the date of the 2024 keynote first. I'll search.
ACTION search("Jensen Huang 2024 keynote date")
OBSERVATION CES 2024 keynote: January 8, 2024.
The model decomposes before acting — it does not assume the date.
THOUGHT "The day after" is January 9, 2024. I need NVDA's close that day.
ACTION price_lookup("NVDA", "2024-01-09")
OBSERVATION Returned: $53.13 (split-adjusted close).
A second tool call, parameterized by the prior observation.
THOUGHT The value is split-adjusted. I should confirm units before answering.
ACTION verify("NVDA close 2024-01-09 split adjusted")
OBSERVATION Confirmed: post-10:1-split adjusted figure.
The model checks an ambiguity rather than hallucinating certainty.
THOUGHT I have a verified, dated, unit-clear figure. I can answer.
ACTION finish("NVDA closed at $53.13 on Jan 9, 2024 (split-adjusted).")
Termination: the model emits a final answer, not another action.

§ 4

Where Loops Fail

Every iteration of the loop appends its thought, action, and observation to the context. The window grows monotonically and accelerates: tool outputs are verbose, and reflections compound. Long before the hard token limit, effective attention degrades — the model loses the thread of its own earlier reasoning. The agent does not crash; it quietly forgets what it was doing, repeats actions, and drifts.

Most production agents fail somewhere in this region — not because the model is incapable, but because the context has become longer than the model's effective attention.

§ 5

The Loop, in Code

# minimal ReAct loop def react(query, tools, model, max_iter=10): context = [system_prompt(), user(query)] for step in range(max_iter): thought = model.generate(context) context.append(thought) if thought.is_final: return thought.answer action = parse_action(thought) result = tools[action.name](**action.args) observation = format_obs(result) context.append(observation) return fallback(context)
THINKThe model generates a reasoning trace from the running context — and may decide it is finished.
ACTThe thought is parsed into a structured call; the named tool is invoked with its arguments.
OBSERVEThe result is formatted and appended, becoming new context for the next THINK.

The structure strictly interleaves reasoning and action. Forcing the model to externalize its thought before acting gives the system interpretability and reduces hallucinated state changes.

§ 6 · Ending

The architecture is the loop. Everything else is a refinement of how the loop decides what to do next.
