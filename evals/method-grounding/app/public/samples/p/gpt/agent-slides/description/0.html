§ 1. The Loop

The ReAct loop is a small control structure around a language model. At each turn the model first writes a thought: a compact account of what it believes, lacks, or intends. It then selects an action, usually a tool call, query, or message to the outside world. The environment returns an observation, which is appended to the trace and becomes evidence for the next thought. Nothing mystical is required. The intelligence comes from repeatedly binding private reasoning to public effects, then forcing the next decision to acknowledge what actually happened.

§ 3. Four Architectures

REACT. A single recurrent controller alternates reasoning, tool use, and observation.
REFLEXION. The loop writes lessons into memory and consults them on later turns.
PLAN-AND-EXECUTE. A plan constrains the local loop without replacing feedback.
TREE-OF-THOUGHTS. Candidate thoughts branch and are evaluated before action.

§ 4. Where Loops Fail

Agent loops accumulate their own history. Tool outputs, failed attempts, partial plans, and self-critiques all enter the context, and the trace soon becomes the environment the model must reason inside. The failure is gradual: attention becomes less selective, stale observations look current, and the controller repeats work. Long before the formal context window is full, effective attention can be exhausted by a trace too large to inspect.

Most production agents fail somewhere in this region — not because the model is incapable, but because the context has become longer than the model's effective attention.

§ 5. The Loop, in Code

def react_loop(model, tools, question, max_steps=8): trace = [{"role": "user", "content": question}] for step in range(max_steps): thought = model.complete( trace + [{"role": "system", "content": "Write the next THOUGHT."}] ) trace.append({"role": "assistant", "content": "THOUGHT: " + thought}) action = model.complete( trace + [{"role": "system", "content": "Choose one tool call or FINAL."}] ) trace.append({"role": "assistant", "content": "ACTION: " + action}) if action.startswith("FINAL"): return action.removeprefix("FINAL:") name, args = parse_tool_call(action) result = tools[name](**args) observation = summarize(result) trace.append({"role": "tool", "content": "OBSERVATION: " + observation}) return model.complete(trace + [{"role": "system", "content": "Answer from the trace."}])
THINK step: the model makes its current state explicit before it changes the world.
ACT step: the controller permits exactly one external move, making causality inspectable.
OBSERVE step: the environment, not the model, supplies the new evidence for the next turn.

The structure strictly interleaves reasoning and action. Forcing the model to externalize its thought before acting gives the system interpretability and reduces hallucinated state changes.

§ 6. Ending

The architecture is the loop. Everything else is a refinement of how the loop decides what to do next.
