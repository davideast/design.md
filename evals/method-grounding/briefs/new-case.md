# Brief — new case

Design a desktop web page where a maker starts a new case from a single fragment of an idea. The page's job is to make starting feel smaller than a form: one input, one action. This brief carries content only — all visual direction comes from the project's DESIGN.md.

The page contains, in sequence:

## 1. Wayfinding

A link back to the case gallery and the page's name: "New case."

## 2. The spark

One text input with the label "Start with a spark — a fragment is enough; an ideation agent helps you find the world before any files exist," and example text inside it: "a tide chart for surfers · a zine for a synth meetup · my grandmother's recipe box…" One action: "Start ideating." One sentence beneath: "A conversation, not a generator — diverge on worlds, converge on a brief and a direction, commit when it's yours."

## 3. The expert path

A collapsed secondary section titled "You already know the world — create a draft directly," containing: an input for the case's short name (example: "recipe-card"), a device choice (desktop, mobile, tablet), and a larger input for the full content brief with the label "The brief — everything the deliverable must contain. The agent handles tokens, groundings, and treatments; you steer it in the editor." One action: "Create draft."
